## Como testar sem Firebase

Build com chaves falsas (só para ver a UI): `VITE_FIREBASE_API_KEY=fakekey123 VITE_FIREBASE_AUTH_DOMAIN=x.firebaseapp.com VITE_FIREBASE_PROJECT_ID=x VITE_FIREBASE_STORAGE_BUCKET=x.appspot.com VITE_FIREBASE_MESSAGING_SENDER_ID=1 VITE_FIREBASE_APP_ID=1:1:web:1 npx vite build --outDir /tmp/dist-fake`, depois `npx vite preview --outDir /tmp/dist-fake`. Os dados reais precisam da conta dela.

## Deploy (só quando o Vini pedir)

`npm run build && firebase deploy --only firestore,hosting` e, antes, `grep -c "<apiKey>" dist/assets/*.js` tem de dar 1 (ver `HANDOFF.md` de 17-09-2026 sobre o `.env`).
