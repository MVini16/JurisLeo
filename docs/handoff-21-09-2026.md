## armadilhas

- **Shell:** blocos com muitas aspas e heredocs falham no bash da ferramenta. Escrever ficheiros com a ferramenta de escrita, ou scripts Python num ficheiro.
- **Lint:** `npx eslint src`, não `npm run lint` (apanha a pasta `repos/`).
- **CSS:** `html.dark .x` tem mais especificidade do que `.x.nivel-1`; já apagou o mapa de calor no escuro uma vez.
- Não ligar `position: fixed` a descendentes de um elemento com `transform` preso: as animações de página usam `animation-fill-mode: backwards` por isso.
